# C1 — خطة تنفيذ محددة للمراجعة

2026-10-25 · **PLAN ONLY — لا تفويض لكتابة كود تشغيلي، ولا قاعدة أو migration أو اختبار C1 منفذ.**

اعتمد المالك اتجاه المعمارية في [PR16](https://github.com/elias-mujally/dbl-products-memory/pull/16) مبدئيًا، وطلب هذه الخطة قبل التنفيذ. خط الأساس للمقترح هو commit الذاكرة `e3a098d5f1d957b66dda94c853e2c79e8c7886c6`. تبقى نتائج Stage B اصطناعية، ولا تعني تأهيل ERP أو مزامنة تشغيلية. لا يُدمج أي PR ضمن هذه المهمة.

## القرار التنفيذي الموصى به

أوصي بأبسط تطبيق آمن لمبادئ PR16: **Catalog مستقل داخل حزمة storage-sqlite الحالية، بمخطط صغير ومعاملة قبول خاصة، دون إعادة هيكلة كاتب V1.** نعيد استخدام أنواع Product والتحقق الأساسي وSnapshotReader، لكن لا نستدعي commit العام ثم نُلحق دليل القبول به. تتشارك بيانات Catalog ودليلها وhead وحدث قبولها قاعدة واحدة جديدة؛ لا تنقسم على قاعدة control وأخرى inventory.

هذا **تنقيح تنفيذي يحتاج مراجعتك**: PR16 ترك خيار توسيع الجداول/الكاتب المشترك. فحص الملفات أظهر أن ذلك يوسّع التغيير إلى إدارة staging والتعافي والتدقيق ومسارات عامة مثبتة. البديل المحدود يفصل جداول Catalog ولا يغيّر migrations 1–4 أو حسابات V1 أو Canonical Product الحالي. يضيف بروتوكول قبول وقراءة صريحين للمصدر الجديد فقط.

## مقارنة التكلفة والتعقيد

تقدير نسبي هندسي، لا أيام عمل أو قياس أداء. لا توجد دراسة تنفيذ تثبت مدة أو عدد أسطر.

| الخيار | تكلفة البداية | التعقيد والمخاطر | التكلفة اللاحقة |

## ما لا نؤجله وما نؤجله

لا يؤجل مصدر الشركة، أو إثبات الاكتمال، أو ذرية head والتدقيق المحلي، أو منع الالتفاف، أو التكرار والتعارض والتعافي من process crash. تؤجل وصلة audit SQLite الخارجية وأثر rollback لنسخة حالة قديمة ضد مصدر حي والتأهيل الفعلي للمُصدر؛ لا تؤجل أحداث القبول المحلية الدائمة. التفاصيل تربط كل عائلة اختبار S1–S5 أو التأجيل المبرر.

**أول تجربة مستقبلية:** إنشاء مجلد مؤقت جديد حصريًا في بيئة التطوير الموجودة، وCatalog SQLite جديدة بمخططها فقط، بشركتين اصطناعيتين. لا نسخ V1، ولا فتح Preview1 أو قواعده، ولا إنشاء VM أو شبكة أو تبعيات جديدة.

هذه الخطة لا تقف عند الاصطناعي: تحدد مخرجات تأهيل مورد/إصدار واحد ومصدر مصرح به بعد C1، تشمل المفتاح الثابت وهوية الشركة واتساق الاستخراج والصلاحيات والتوقيع والمطابقة المرجعية. إذا لم تثبت هذه الحقائق يبقى الموصل الحقيقي محجوبًا؛ نجاح C1 لا يبدلها.
