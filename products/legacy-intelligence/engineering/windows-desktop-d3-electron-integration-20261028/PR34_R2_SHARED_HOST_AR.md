## Host وPreload اللذان نفذهما Codex

وحدة مستقلة جديدة تحافظ على تجربة PR #33 وملفات D2 الخلفية. namespace المشترك الوحيد هو window.dblDesktop.inventory، بخمس عمليات المخزون الحالية ونفس Channel/DTO وApplication Service. لا invoke عام أو وصول Renderer إلى SQLite أو الملفات.

InventoryClient وقارئ PR #32 منفصلان عن عامل D2. يبدأ D2 عند طلبه ويكتب fixture اصطناعية جديدة في output مستقل. حراس sender والإطار وURL وschema وpins وCSP وsandbox باقية. output لا يتقاطع مع أي مصدر أو Runtime. ردود D2 مقيدة بالحقول والسياق، وclose قديم لا يلغي سياق مخزون أحدث. تصنيف V1 الفعلية ما زال مرفوضًا.

نجح12 اختبارًا Native مع Runtime موجود ومع staging جديد؛ التكرار لا يعني24 حالة مختلفة. أول setup محلي تعثر لفقد مجلد القارئ في نسخة المراجعة؛ حُفظ الفشل واستُكمل النسخ دون تغيير القارئ.
