# Dynamic ERP ingestion — bounded engineering review

2026-10-25 · **REVIEW AND EXISTING SYNTHETIC TESTS ONLY; IMPLEMENTATION NOT APPROVED.**

النتيجة: البنية العامة مناسبة للتوسع، لكن مسار V1 ليس موصلًا عامًا. قيد الخمسة يحمي عينة مؤهلة، ويظهر في الجمع والتحقق والمشغّل؛ حذفه لا ينتج مزامنة سليمة. يمكن إعادة استخدام Canonical وموصلات buffered/batched والاستيراد الذري والتخزين التاريخي والتدقيق والقراءة، مع تصميم قبول مصدر كامل وهوية مستقرة وبروتوكول تشغيل أعم.

**التوصية:** ابدأ بعقد تصدير كامل لـ**دليل الأصناف** وملفات متجددة يختارها المشغّل، ثم اقبل نسخة محلية جديدة في DBL بعد تأهيلها. لا تبدأ بحساب أرصدة مخزون عام أو اتصال حي أو جدولة أو CDC. ديناميكية البيانات داخل mapping مورد/إصدار معروف لا تعني اكتشاف مخطط أي ERP أو تفسيره تلقائيًا.
