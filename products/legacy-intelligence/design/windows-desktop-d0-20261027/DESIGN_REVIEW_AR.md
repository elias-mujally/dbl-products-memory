# D0 — مراجعة الاتجاهات وحدود ما تم

## ما أنتجناه فعليًا

ثلاثة طلبات توليد مستقلة بأداة ImageGen المدمجة، باتجاه واحد لكل طلب، ولقطات متعددة للحالات داخل الاتجاه نفسه وفق طلب المالك. لا نموذج HTML/CSS لتطبيق DBL أو Electron أو IPC أو محرك. المعرض HTML وثيقة صور بلا JavaScript، والصور المضمنة هي PNG الأصلية دون تحويل أو تحرير بكسلات. الأبعاد الفعلية مسجلة؛ ليست مطابقة تلقائيًا لأبعاد prompt المطلوبة.

استخدمنا نصوص دراسة PR #22 ولغتها البصرية وقرارات D0. لم تكن هناك صورة واجهة DBL سابقة محددة من المالك أو design context محفوظ؛ لم ندّع إرفاق مرجع بصري غير موجود. تلقى كل طلب بيانات العينة والتاريخ والحدود نفسها، دون أي بيانات خاصة أو ERP.

## العينة الثابتة

شركة عرض DBL، مصدر عرض اصطناعي، لقطة DEMO-20261027-A، وقت2026-10-27 الساعة09:00 UTC+03. الرموزSYN-101 إلىSYN-105 وأسماء ورق طباعة/حبر أسود/ملف أرشفة/لوحة مفاتيح/فأرة حاسوب، ومعرفات عينةDEMO-101 إلىDEMO-105. هذه المعرفات لا تستنتج هوية i_code أو أي مفتاح ERP. الملف المعروضdemo-catalog-20261027.json اسم تصوري، وليس مصدرًا حقيقيًا جرى التحقق منه.

تظهر «نموذج تصميم — بيانات اصطناعية» و«غير مؤهل لـ ERP». مراحل الاستيراد مكتوبة كمحاكاة؛ التأكيد لا يمنح ملفًا حقيقيًا حق تجاوز القبول، والنتيجة تنص على أنه لا استيراد فعلي ولا كتابة. لا أرصدة أو أسعار أو مبيعات أو صلاحيات مخترعة.

## توصية ونقطة توقف

نرشح الاتجاه1 كأساس مؤسسي متوازن للمالك والمحاسب، مع بقاء2 بديلًا إذا أُعطيت الأولوية للعمل المحاسبي المتكرر، و3 إذا أُعطيت الأولوية للتعلم والاستيراد المساعد. لا نختار نيابة عن المالك أو نمزجها تلقائيًا. بعد الاختيار يمكن إنتاج تنقيح بصري، ثم يحتاج D1 إذنًا منفصلًا للتقنية والتبعيات والربط.

## السلامة والاحتفاظ

حُفظت نسخ الصور في مساحة العمل وبقيت مخرجات التوليد الأصلية محفوظة. طابقت SHA-256 قبل/بعد النسخ ومع bytes المضمنة في gallery. الفحص يثبت سلامة الأصول المرئية، لا صحة مصدر ERP. لا Git merge أو Preview1 أو ERP أو SQL أو بيانات عميل أو خزنة أو إعدادات نظام/شبكة/أمان أو dependencies تشغيلية.

مسار رفع الملفات الثنائية من أداة shell تعذر بسبب قيد اتصال؛ لم يُعد أو يُرفع إذن أو تتغير إعدادات. حزمة المراجعة تستخدم واجهة GitHub المتصلة المسموح بها لملفات نصية ومعرض HTML ذاتي الاحتواء، بدل تشغيل ناقل غير مسموح أو نشر خدمة صور عامة. PNG الأصلية متاحة محليًا وفي الصور المسلمة؛ المعرض يحتفظ ببايتاتها كاملة.
