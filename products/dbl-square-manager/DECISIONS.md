# Decisions

## Repository boundaries — 2026-11-05

The implementation repository is private. This product-memory repository remains public and contains only publication-safe product context. Private source, credentials, local drafts, and operational state are excluded from public memory.

## Publishing controls — 2026-11-05

A new publication requires an explicit user action and confirmation of the reviewed content and destination. Attempt records are separate; uncertain outcomes are not retried automatically. The initial publication evidence is retained. These decisions do not imply exactly-once delivery or API identity verification.

## Product direction

The final product vision remains open. No scheduling or autonomous publishing has been approved.
